Privacy Policy

Vengeance: The Norian Chronicles

Last updated: October 7, 2026

Vengeance: The Norian Chronicles is designed as an offline single-player game.

Data Collection

The current version of Vengeance: The Norian Chronicles does not collect, transmit, sell, or share personal information.

The game does not use advertising, analytics, user accounts, location services, or tracking technologies.

Game Saves and Settings

Game progress and application settings are stored locally on the user's device. This locally stored game data is not transmitted to the developer.

Removing the application or clearing its local application data may remove locally stored game progress.

Third Parties

The current version does not provide personal information to third-party advertising or analytics services.

Changes to This Policy

If the application's data practices change in a future release, this policy will be updated to reflect those changes.

Contact

For privacy-related questions, please use the Vengeance support page.
